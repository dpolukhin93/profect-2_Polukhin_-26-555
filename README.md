# Primitive DB

Учебная база данных на Python с поддержкой команд стандартных CRUD-операций (вставка, чтение, обновление, удаление).
Данные хранятся в JSON-файлах (папка "data\"), схема таблиц описывается метаданными (файл "db_metadata.json").
Исходный код проекта доступен на GitHub: [https://github.com/dpolukhin93/profect-2_Polukhin_-26-555/tree/main/src/primitive_db] 
## Требования

- **Python 3.12+**
- **[uv](https://docs.astral.sh/uv/)** — менеджер пакетов и окружений

## Установка и настройка
Для установки необходимо:
1. Клонировать репозиторий:

git clone [https://github.com/dpolukhin93/profect-2_Polukhin_-26-555/tree/main/src/primitive_db] %Папка_проекта%
cd %Папка_проекта%

2. Установка проекта. В папке проекта в консоли необходимо выполнить следующие команды:
uv sync
uv build

3. Запуск. После установки проекта он может быть запущен командой
uv run database

## Работа с программой
Программа поддерживает следующие команды:

| Команда | Синтаксис | Описание |
|---------|-----------|----------|
| `create_table` | `create_table <имя_таблицы> <столбец1:тип> <столбец2:тип>..` | Создать таблицу |
| `drop_table` | `drop_table <имя_таблицы>` | Удалить таблицу |
| `list_tables` | — | Показать список всех таблиц |
| `insert` | `insert into <имя_таблицы> values (<значение1>, <значение2>, ...)` | Создать запись |
| `select` | `select from <имя_таблицы>` | Прочитать все записи |
| `select` | `select from <имя_таблицы> where <столбец> = <значение>` | Прочитать записи по условию |
| `update` | `update <имя_таблицы> set <столбец1> = <новое_значение1> where <столбец_условия> = <значение_условия>` | Обновить запись |
| `delete` | `delete from <имя_таблицы> where <столбец> = <значение>` | Удалить запись |
| `info` | `info <имя_таблицы>` | Вывести информацию о таблице |
| `exit` | — | Выход из программы |
| `help` | — | Справочная информация |
